Conversation flow

把注意力留在问题上

以前

找文件 → 复制 → 粘贴 → 补上下文

每一次对话都要在网页、资料和工具之间来回切换。

现在

正常提问 → 按需获取 → 确认调用

模型通过明确的 Harness 命令请求需要的内容，实际 MCP Tool 调用仍由你确认。

Only what is needed

按需协作，不预先塞满对话

先披露目录，再读取实际需要的 Skill、Reference 或 MCP 服务详情；每次 Tool 调用都清楚地留给你决定。

  1. 01

    正常提问

    从你原本的网页 Chat 对话开始。

  2. 02

    按需读取

    模型显式请求需要的 Skill、Reference 或服务详情。

  3. 03

    确认调用

    调用 MCP Tool 前展示名称与结构化参数。

  4. 04

    继续回答

    把真实结果回到同一段对话，完成当前问题。
